## Availability

There are currently **no installable formulae on `main`**. Formula development
is in progress; this README does not advertise a working package install yet.

## Using this tap

You can register the tap with Homebrew:

```sh
brew tap XJM-free/tap
```

Once a formula has been reviewed and merged, inspect its source and release
before installing it. Future formulae will use the fully qualified pattern
`XJM-free/tap/<formula>`; `<formula>` is a placeholder, not an available package.

## Release policy

Formulae should point to stable, checksum-pinned upstream releases. Formula
changes and bottle publication require human review.

See [Homebrew's Tap documentation](https://docs.brew.sh/How-to-Create-and-Maintain-a-Tap)
for trust and installation details.
